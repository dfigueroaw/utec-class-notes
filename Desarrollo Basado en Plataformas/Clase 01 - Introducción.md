### Protocolos para comunicarse con un API
- SOAP
- **REST**
- GraphQL
- gRPC

- **URI**: Identificador genérico de un rescurso, puede ser una URL o URN. **IDENTIFICA A UN RECURSO DE MANERA ÚNICA**
- **URL**: Tiene varias partes
	- Protocolor
	- Dominio
	- Path (Ruta)
	- File Name o endpoint (URI)

Metodos HTTP:
- GET
- PUT
- POST
- DELETE

Seguridad: Se refiere a que el método HTTP no modifica el recurso en el servidor
Idempotencia: Se refiere a que múltiples solicitudes
