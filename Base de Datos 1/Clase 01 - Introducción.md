### ¿Qué es una base de datos?
Una base de datos es una colección de datos los cuales respetan cierto esquema de organización para facilitar consultas eficientes.

Por otro lado, un sistema para manejar bases de datos es una herramienta que nos permite manejar ...
. También se conocen como **DataBase Management System (DBMS)**.
