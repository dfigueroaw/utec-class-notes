### ¿Qué es una base de datos?
Una base de datos es una colección de datos los cuales respetan cierto esquema de organización para facilitar consultas eficientes.

Por otro lado, un sistema para manejar bases de datos es una herramienta que nos facilita representar, cargar, organizar, definir actualizar, consultar datos. También se conocen como **DataBase Management System (DBMS)**. Los DBMS se encargan de optimizar el almacenamiento, la indexación, el manejo de transacciones (concurrencia), la seguridad y el procesamiento de consultas, sin embargo el mismo programador también se debe encargar de optimizar las consultas
